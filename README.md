# 쉼, 바다

눈을 감으면 도착하는 바다.
파도와 종달새 소리를 섞어, 소중한 사람에게 편지와 함께 보내는 작은 휴식 웹앱.

## 특징

- **오디오 파일 없음** — 12가지 소리를 브라우저에서 Web Audio로 직접 합성
  파도 · 갈매기 · 바람 · 종달새 · 아침새 · 비 · 천둥 · 시냇물 · 귀뚜라미 · 모닥불 · 풍경 · 싱잉볼
- **프리셋 6종** + 날짜마다 달라지는 "오늘의 바다"
- **수면 타이머** — 끝날 때 천천히 페이드아웃
- **호흡 가이드** — 파도가 밀려오는 리듬에 맞춰 들숨/날숨
- **화면 어둡게 모드**, 화면 꺼짐 방지(Wake Lock)
- **믹스 자동 저장** — 다시 들어오면 마지막 믹스 그대로
- **바다 선물하기** — 받는 이 이름 + 편지 + 지금 믹스를 링크 하나로 압축
  서버에 아무것도 저장하지 않음. 전부 URL 해시(`#g=1.…`) 안에 들어감

## 구조

단일 파일 정적 사이트. 빌드 과정 없음.

```
index.html              앱 전체 (마크업 + 스타일 + Web Audio 엔진)
manifest.webmanifest    PWA 매니페스트
icon-180.png            애플 터치 아이콘
icon-512.png            PWA 아이콘
og.png                  공유 미리보기 이미지
vercel.json             정적 호스팅 설정 (cleanUrls, 캐시 헤더)
```

## 로컬에서 실행

```bash
python3 -m http.server 8899 --bind 127.0.0.1
# http://127.0.0.1:8899
```

브라우저 정책상 첫 재생은 사용자 탭/클릭이 필요하다.

## 배포

Vercel 정적 배포.

```bash
npx vercel --prod
```

배포 후 `index.html`의 `og:image`를 절대 URL(`https://<도메인>/og.png`)로 바꿔주면
카카오톡·슬랙 등에서 미리보기가 제대로 뜬다.

## 선물 링크가 만들어지는 방식

앱 안의 "이 바다를 선물하기"에서 받는 이 이름 · 편지 · 지금 믹스를 입력하면

```
{ n, l, m }  →  JSON  →  deflate-raw  →  base64url  →  #g=1.<payload>
```

CompressionStream을 못 쓰는 브라우저에서는 압축 없이 담긴다(`#g=0.…`).
편지가 담긴 링크로 들어오면 달을 세 번 두드릴 때 편지가 열린다.
받는 이의 믹스는 링크당 한 번만 적용되고, 그 뒤로는 각자 자유롭게 섞을 수 있다.
